# Track Day Log

A mobile-first progressive web app for amateur track-day drivers.

## V1
- Generic first-run experience: add any car, then create track days.
- Garage with tyre and baseline pressure details.
- Preparation and packing checklists with completion timestamps.
- Session logging for lap time, four tyre pressures, fuel, brakes, temperatures, notes and adjustments.
- End-of-day jobs and notes.
- Track-day history.
- Device-local storage with JSON export/restore backup.
- Offline-capable PWA with Home Screen manifest and icon.

## Data
V1 deliberately keeps each user's data on their own device. Cloud/account sync can be added later without changing the basic user flow.
